01 Applied AI · Python

Ehtobotti

A chatbot that answers questions about insurance terms and tells you which section and page the answer came from.

Insurance terms are long PDFs that hardly anyone reads. I wanted to see if a small language model running on my own laptop could answer questions about them without making things up. If the answer isn't in the terms, the bot says it couldn't find one.

  • Retrieval pipeline written from scratch without LangChain: PDF parsing, chunking along the documents' own numbered headings, bge-m3 embeddings and Chroma vector search.
  • The code checks every citation. If the model cites a passage it was never given, the user sees a warning.
  • Runs entirely on a laptop GPU through Ollama, so questions never leave the machine.
  • Measured on a hand-checked question set. I chose the smaller model because the bigger one invented an answer.

02 C++ · AI-assisted coding Coming soon

Chess

I made the same chess game twice, once with Claude Code and once with ChatGPT, to compare the two tools on a real C++ project.

Both are desktop apps written in C++17 with SFML 3. You play against a bot on Easy, Medium or Hard, and all the normal rules work, including castling, en passant and promotion. Both versions ended up at around 4,000 lines, but they are built quite differently:

Claude Code ChatGPT
Structure Rules and bot in their own libraries, no graphics code Game loop, menus and input in one 1,500-line main.cpp
Bot Alpha-beta, iterative deepening, quiescence search Minimax with alpha-beta, 2–4 moves deep
Tests ~600 lines: perft on 6 positions, mate and tactics tests Tested by hand
Draws Repetition, fifty-move rule, insufficient material Stalemate, threefold repetition
  • C++17
  • SFML 3
  • CMake
  • Claude Code
  • ChatGPT

03 Unity · C# · Game jam

04 JavaScript · Canvas

Cool RPG-Game

My final project in vocational college. It's a top-down action RPG that runs in the browser: you walk around a castle, fight enemies and finally a boss.

I made it with plain JavaScript and the Canvas API, without a game engine, so the game loop, animations and collisions are all my own code. The map is made in Tiled.
